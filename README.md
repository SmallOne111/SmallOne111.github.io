> 男生从小到底被教了些什么？小时候摔一跤，哭了
“男孩子哭什么？”
上学的时候成绩不好
“一个男生以后没本事怎么行？”
长大了谈恋爱
第一次出去吃饭
很多人的第一反应就是男生买单。
你要是让女生付，旁边可能马上就有人说：“跟女生吃饭还让女生付钱？”
吃完饭去看电影，男生买票
喝奶茶，男生买
打车，男生付
好像两个人谈恋爱以后，只要账单放到桌子上，男生就应该自动把手机掏出来
然后到了结婚
房子呢？最好男方买
车呢？最好男方买
彩礼呢？男方给
婚礼呢？男方家里操办
结婚以后呢？还得赚钱养家
最有意思的是，有时候你根本没要求这些，别人就已经替你安排好了
你说彩礼太高了
“不给彩礼就是不想娶”
你说房子买不起
“连房子都没有，拿什么结婚”
你说压力太大
“男人有压力不是很正常吗”
你说想让两个人一起承担
又有人说“你一个大男人，让女人养你”
所以我一直觉得挺奇怪
为什么男人只要不愿意承担某些东西，就很容易被扣上“不像男人”的帽子？但女人不愿意做传统意义上的那些事情，我们却越来越能够理解
我觉得这其实没什么问题
女人当然应该有选择自己怎么生活的权利
那男人为什么不应该有？我不是说女生吃饭就不能让男生买，也不是说结婚就一定不能给彩礼
喜欢一个人，愿意花钱，这很正常
男生愿意买单，女生愿意回请也很正常问题在于“愿意”和“应该”不是一回事
我愿意给你买，是因为我喜欢你
但不是因为我是男人
我愿意为家庭努力赚钱，是因为这是我的家
但不是因为别人告诉我“男人就该养家”
我愿意给彩礼，也可以是我的心意
但如果变成“不拿这么多钱就别想结婚”
那我觉得这已经不是心意了
说到底，我反感的不是女人，也不是婚姻
我反感的是那种从出生开始，就按照你的性别给你安排好人生的感觉
男孩子就得坚强
男人就得赚钱
男人就得主动
男人就得买单
男人就得买房
男人就得给彩礼
男人就得养家
那如果我不想呢？
我是不是也可以说“不”？
我觉得可以
而且这并不代表男人就可以什么责任都不承担
两个人过日子，本来就是商量，谁收入高，谁多承担一点
谁手里宽裕，谁多出一点
谁愿意买单就买单
彩礼谈得拢就谈，谈不拢就算了
没必要非得把一个男人逼到“证明自己是男人”的地步，才允许他结婚
所以现在有些男生开始讨论这些东西，我觉得没什么可怕的
他们不是突然不爱女人了
只是终于开始问：“为什么有些事情，只因为我是男人，就默认该由我来承担？”这个问题，我觉得其实挺值得想一想
