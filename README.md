## 这个暑假被我毁了(2026-09-04)

7月1日，下午期末考完放假，我的初二学习生活正式结束。

那时我满心对暑假的期待，我幻想着每天充实的学习。

然而，事与愿违。

我早早地做好了详尽的记录，细致到几点几分做什么学科的什么内容。

我以为计划一丝不苟地进行，但事实是：

天气太热，懒得大老远跑图书馆，直接在家躺平；

以为每天能完成的任务，实际上根本超量。

意外也总是不请自来：用于上网看教学视频的电脑总是出问题，大部分时间花在捣鼓电脑上面。

我想象中的暑假：每天按时完成学习任务，并将我与▒▒（我的编程搭档）共同推进我俩的项目。

现实的暑假：暑假**前一个半月**几乎没碰过书，时间全花在编程和配置我的服务器上（这是一项相当耗时的项目）

……

暑假的最后一周，我开始赶作业，到最后几乎全是抄的答案。

31号，开学在即，我熬了整个通宵。

这是多么愚蠢！

在此，我无能长篇大论地剖析我拖延等的陋习，但我知道我未来所该做的：

- 严格规划电脑时间，并使用屏幕时间控制相关工具
- 总是先完成学习，至少在一个上午/下午的时间范围内
- 在实践中完善计划，而不是提前在计划上画大饼
- 不要~~熬夜~~，就算真的无法完成任务，天也不会塌

将此篇，警诫现在及未来及永远的我。
